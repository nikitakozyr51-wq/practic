# Перенос в проект «отчет Max»

Пакет подготовлен 21.10.2026. Файлы и существенный контекст сохранены, но эта операция не создаёт чат и не добавляет файлы в интерфейс проекта автоматически.

1. Скачай полный ZIP репозитория по ссылке из сообщения и распакуй его. В нём есть исходные документы, извлечённые иллюстрации, старые Word/PDF, проверки, скрипты и папка handoff/max с новыми инструкциями. История Git и полная переписка в этот ZIP не входят.
2. Открой уже созданный проект «отчет Max» в ChatGPT.
3. В файлы проекта добавь handoff/max/START_HERE_MAX.md. Для работы с требованиями и примерами также загрузи из practice-project/originals методичку PDF, один бланк задания, Nazar_Otchet_Praktika.docx и ОТЧЕТ.docx. Повторную копию задания загружать необязательно.
4. В инструкции проекта вставь текст PROJECT_INSTRUCTIONS_MAX.txt, если в интерфейсе есть соответствующее поле.
5. Создай внутри проекта новый чат и отправь текст FIRST_MESSAGE_MAX.txt. После этого присылай новые фотографии и документы одногруппника именно туда.

Полный ZIP хранит весь набор файлов. Если интерфейс проекта не принимает архив, загружай распакованные документы по отдельности. Для анализа новых приборов фотографии нужно передавать как доступные изображения, а не рассчитывать только на их наличие внутри Word или ZIP. Анализ изображений из документов зависит от возможностей нового чата.

В старом проекте уже есть отчёт с личными данными пользователя; новый START_HERE_MAX.md объясняет, что это исторический пример, а новый автор и его судно определяются отдельно. Старый файл practice-project/START_HERE.md ведёт в прежнюю работу и не является стартовой инструкцией для «отчет Max».

Если нужна дословная история сообщений, её перенос или экспорт выполняется через доступные функции интерфейса. Содержимое START_HERE_MAX.md представляет собой рабочий контекст, а не выгрузку всей переписки. Плагины и настройки облачной среды из ZIP в другой чат не устанавливаются.
