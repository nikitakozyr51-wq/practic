### Сохранённая настройка сети

В черновик среды записаны только необходимые адреса: www.google.com, tass.ru, www.imo.org, search.rsl.ru, www.skipper.no, www.jotron.com. Пресет пакетных менеджеров и остальные поля сохранены. Инструмент подтвердил status=saved и requires_publish=true: это сохранение черновика, а не доказательство применения или публикации. Для активации продукт требует проверить/сохранить изменения в настройках среды, затем опубликовать среду. Состояние текущих запросов учитывается отдельно от сохранённого списка.

## Правила библиографии итогового отчёта

- Не включать источник только для создания вида библиографии.
- Различать существование книги, доступ к нужному разделу и поддержку конкретного утверждения.
- При использовании учебника проверять автора, название, издание, год, издательство и нужные страницы/главу.
- Для оборудования отдавать приоритет руководству конкретной модели; русскоязычный учебник поддерживает общий принцип, но не судовую комплектацию.
- Открытая информация о корабле не подтверждает фактическое выполнение пользователем судовых операций.
