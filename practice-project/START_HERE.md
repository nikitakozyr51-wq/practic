# Продолжение проекта

Сначала прочитать analysis/PROJECT.md, PLAN.md, ERROR_LOG.md, ASSIGNMENT_CHECK.md и DRAFT_REVIEW_NOTES.md. Основная версия — analysis/report.docx, исходный текст — REPORT_CONTENT.md, печатный просмотр — report.pdf. Старое имя draft-report.docx синхронизировано с текущим файлом.

Подтверждённые реквизиты: Козырев Никита Алексеевич; группа С-612, 6-й курс по согласованному образцу; корабль «Чабаненко», военный; Североморск; 03.06.2026–08.07.2026; один месяц шесть дней; палубный кадет / DECK CADET. Поля справки: GT 7570, propulsion power 62 000 кВт, GTA M-9, электрическое оборудование 5200 кВт. Не путать GT с водоизмещением и не возвращать ошибочную должность «плавучий кадет».

Справка показана двумя снимками в чате, её поля прочитаны. Но эти изображения не имеют доступных локальных файлов: нужно получить их как JPG/PDF и вложить в приложение Б. Не создавать справку заново и не менять подпись или печать. Сборщик поддерживает две страницы JPG/PNG в originals/certificate; перед вставкой осмотреть исходные изображения.

Пользователь требует оформление Назара по шрифту, цвету, размеру, полям и титулу. По последнему уточнению разрешены также изображения приборов из интернета. Семь исходных фотографий сохранены; добавлены четыре настоящих изображения Jotron/SKIPPER без вида палубы. В разделе 5 — десять рисунков, в 6.1 — общий вид мостика. В нескольких исходных кадрах подписаны дополнительные приборы. АИС среди них уверенно не идентифицирована; её пример взят у производителя. Изображения не генерировались. Точное наличие моделей на корабле не подтверждено. Пользователь просил выдавать их наличие за факт, однако такое утверждение в текст не внесено.

Комментарий Назара: подробный ТСС, подписанные приборы, литература, задание и справка. Пользователь ответил, что 50–60 страниц не являются точным минимумом: важны содержание и оформление. В PDF сейчас 34 страницы, ТСС — страницы 7–23. Письменная методичка требует 40–50 страниц ТСС и реальные наблюдения; эти требования не объявлять автоматически отменёнными.

Последняя правка: отчёт Максима исключён из литературы и упоминаний в сдаваемом Word, происхождение фото сохранено в рабочих реестрах. Библиография — семь проверенных источников, включая четыре руководства конкретных моделей. Абзацы приведены к основному оформлению Назара; случайные маркеры убраны, фото и подписи центрированы, задание вставлено редактируемым текстом на двух страницах.

Разбор всех 42 тем — ASSIGNMENT_CHECK.md. Подробная проверка текста — THESIS_REVIEW.md, фотографий — MEDIA_ANALYSIS.md, оформления — FORMAT_CHECK.md, использования плагина — ARS_CHECKS.md. Технические источники — TSS_SOURCE_REVIEW.md; краткие пояснения для защиты — TSS_DEFENSE_NOTES.md. Текущие картинки и их номера задаются report-figures.json; полные руководства не включены в репозиторий, их адреса и SHA-256 сохранены. Реальных серий поправок, таблицы девиации, эхограмм, курсограмм и заверенного формуляра нет. Не придумывать их и не выдавать чужие события за практику пользователя. Не повторять остановленное интервью о бытовых работах.

Сборка: python practice-project/build_report.py из корня репозитория. Проверка Word: python practice-project/verify_report.py; проверка PDF: python practice-project/verify_render.py. Для PDF используется LibreOffice. Сохранённые номера страниц рассчитаны по текущей отрисовке; после изменения содержания нужна новая проверка оглавления.

Пользователь разрешил загрузить весь проект, включая исходные отчёты, в nikitakozyr51-wq/practic. GitHub-ссылка на Word заработала; внутренние sandbox-ссылки ранее не скачивались. Не связывать это без доказательств с отсутствием приложения Codex. Плагин ARS-Codex 3.23.0 включён в этой облачной среде; на новом компьютере отдельно проверять установку.
