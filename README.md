## Перенос на Windows

1. В GitHub нажмите **Code → Download ZIP** и распакуйте архив на компьютере. Исходные документы и извлечённые фотографии уже входят в репозиторий.
2. В приложении Codex войдите в свой аккаунт и откройте распакованную папку как проект.
3. Отправьте: «Продолжи подготовку отчёта по практике. Сначала прочитай README.md, practice-project/START_HERE.md и перечисленные там файлы PROJECT.md, PLAN.md, ERROR_LOG.md и DRAFT_REVIEW_NOTES.md. Сохрани уже подтверждённые сведения и не задавай повторно отвеченные вопросы».

Чат предыдущей среды не переносится этим архивом автоматически. Основные факты, решения, ошибки и оставшиеся задачи записаны в Markdown. Плагин ARS-Codex, установленный в прежней облачной среде, нужно отдельно установить на новом компьютере при необходимости.
